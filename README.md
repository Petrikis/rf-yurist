# RF-Юрист — плагин для Claude

Навыки для Claude для работы с российским правом: фактчек норм по первоисточникам, анализ рисков, составление и проверка договоров. Не цитирует закон по памяти и не тащит западные конструкции, которые в РФ не работают.

## Установка

**Claude Code (CLI):**

    /plugin marketplace add <твой-github-ник>/rf-yurist
    /plugin install rf-yurist

**Claude Cowork (десктоп):**

Customize → Plugins → «+» в разделе Personal plugins → Add marketplace → введите `<твой-github-ник>/rf-yurist` → установите плагин **rf-yurist**.

> Замените `<твой-github-ник>` на ваш GitHub-логин после публикации репозитория.

## Что внутри

Плагин **rf-yurist** с четырьмя навыками:

- **rf-pravo-factcheck** — ядро: поиск и проверка нормы по первоисточникам (pravo.gov.ru, КонсультантПлюс, Гарант, ВС/КС, КАД «Арбитр») + проверка применимости в РФ;
- **rf-risk-analysis** — анализ юридических рисков: нормы, ответственность, вероятность, что делать;
- **rf-contract-draft** — составление документов под РФ (договоры, оферта, политика 152-ФЗ, претензия и т. д.);
- **rf-doc-review** — проверка готовых документов на риски и соответствие праву РФ.

Подробнее — в [README плагина](rf-yurist/README.md).

## ⚠️ Дисклеймер

Это инструмент-помощник, а **не юридическая консультация** и не замена юристу. Модель может ошибаться и цитировать неактуальные редакции. Всегда проверяйте первоисточник перед принятием решений; для значимых и рискованных вопросов обращайтесь к практикующему юристу. Встроенные ориентиры по свежим нормам актуальны на **июнь 2026** и со временем устаревают.
