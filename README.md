# RF-Юрист (форк)

Плагин для Claude с навыками для работы с российским правом: проверка норм по первоисточникам, анализ рисков, составление и проверка документов. Подробное описание навыков — в [rf-yurist/README.md](rf-yurist/README.md).

Форк репозитория [gmen1057/rf-yurist](https://github.com/gmen1057/rf-yurist) (автор оригинала — Evgenii, лицензия MIT сохранена, см. [LICENSE](LICENSE)). Версия 0.2.1.

## Установка

Claude Code:

```
/plugin marketplace add Petrikis/rf-yurist
/plugin install rf-yurist@rf-yurist
```

Claude Cowork (десктоп): Customize → Plugins → добавить маркетплейс `Petrikis/rf-yurist` и установить плагин `rf-yurist`.

Если плагин уже установлен из оригинального репозитория, сначала удалите его и маркетплейс `gmen1057/rf-yurist`, затем подключите этот: два маркетплейса с одинаковым именем `rf-yurist` конфликтуют.

## Навыки

- `rf-pravo-factcheck` — общая точка проверки норм: поиск, редакция на нужную дату, применимость в РФ.
- `rf-risk-analysis` — анализ юридических рисков (частный и деловой контекст различаются).
- `rf-contract-draft` — составление документов, в том числе каркасы личных сделок и апелляционной жалобы.
- `rf-doc-review` — проверка готового документа, в том числе «только новых изменений».

## Актуальность норм

В версии 0.2.1 часть норм сверена по первоисточнику (октябрь 2026), остальные помечены. Перед использованием проверяйте действующую редакцию, условия и исключения; для события в прошлом — редакцию на дату события.

## Дисклеймер

Инструмент-помощник, не юридическая консультация. Модель может ошибаться и цитировать неактуальную редакцию — проверяйте первоисточник.
